# ☕ DevStatus — 程序员每日状态报告

> 每天生成一份程序员精神状态报告，看看你今天适不适合写代码。

## 安装

```bash
git clone https://github.com/One1turn/DevStatus.git
cd DevStatus
```

## 使用

```bash
python devstatus.py
python devstatus.py --name "张三"
python devstatus.py --seed 42
```
